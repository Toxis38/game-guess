# Угадай игру

Веб-игра на Node.js: сервер загадывает одну из ~110 популярных видеоигр, ты угадываешь по 3 подсказкам.

## Очки
- 1-я подсказка → **100** баллов  
- 2-я подсказка → **80** баллов  
- 3-я подсказка → **50** баллов  
- Не угадал → поражение

## Гибкий ввод
Можно писать как угодно:
- `киберпанк`, `cyberpunk`, `сайберпанк`, `Cyberpunk 2077`
- `гта 5`, `гта5`, `GTA V`
- `ведьмак`, `ведьмак 3`, `The Witcher 3`

## Запуск

```bash
npm install
npm start
```

Открой http://localhost:3000

## Структура
- `server.js` — Express-сервер + логика
- `data/games.json` — список игр с подсказками и алиасами
- `public/` — фронтенд (HTML/CSS/JS)
