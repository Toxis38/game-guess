# Угадай игру

Веб-игра на Node.js: сервер загадывает игру, ты угадываешь по 3 подсказкам.

## Особенности

- **~270 игр** (обычные + хард)
- **Отгаданные игры больше не повторяются** (сохраняется даже после перезапуска сервера)
- **Подсказки складываются** — видно все открытые, а не только последнюю
- **Режим Хард** — менее известные и нишевые игры
- Гибкий ввод названий (киберпанк / cyberpunk / гта 5 / ведьмак и т.д.)

## Очки
- 1-я подсказка → **100** баллов  
- 2-я подсказка → **80** баллов  
- 3-я подсказка → **50** баллов  
- Не угадал → поражение

## Запуск

```bash
npm install
npm start
```

Открой http://localhost:3000

## Структура
- `server.js` — Express + логика + персистентность
- `data/games.json` — база игр (с флагом hard)
- `data/solved.json` — список уже отгаданных игр
- `public/` — фронтенд

## Сброс прогресса
Кнопка «Сбросить прогресс» на стартовом экране или `POST /api/reset`.
